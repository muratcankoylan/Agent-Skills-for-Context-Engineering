# 005 - Security rotation handoff

Independent hard held-out task for `context-compression`. It was designed after task 003 showed a ceiling effect, but before any task-005 model output was observed.

Predeclared properties:

- 1,300 synthetic turns;
- 1,800-byte output budget;
- 19 exact anchors across nine categories;
- early audit-retention constraints;
- late key-overlap decision, test state, session-loss risk, named approval gate, and next tenant.

The partial-credit scorer reports anchor and category retention even when the binary verifier fails.
